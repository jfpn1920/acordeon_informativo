HTML es el lenguaje utilizado para estructurar el contenido de una página web.

Permite crear títulos, párrafos, imágenes, enlaces, formularios y diferentes elementos de una página.

CSS es el lenguaje utilizado para diseñar y presentar visualmente los elementos de una página web.

Permite trabajar con colores, tamaños, espacios, posiciones, animaciones y diseños responsive.

JavaScript es un lenguaje que permite agregar interactividad a las páginas web.

Puede responder a eventos, modificar elementos HTML y actualizar información dinámicamente.

El frontend corresponde a la parte de una aplicación web con la que interactúa directamente el usuario.

HTML, CSS y JavaScript son algunas de las tecnologías fundamentales utilizadas en frontend.

El diseño responsive permite que una página web se adapte a diferentes tamaños de pantalla.

De esta manera, el contenido puede visualizarse correctamente en móviles, tablets y computadoras.
